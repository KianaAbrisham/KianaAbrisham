# Development notes

The PPG projects build on Kiana Pilevar Abrisham's research and link the related publications. Project research notes document changes from the original notebooks. The other repositories contain learning exercises and applied machine-learning examples.

Subsequent repository development used AI coding assistance for implementation, refactoring, tests, documentation, data preparation, and validation runs.

Each research repository documents its datasets, evaluation methods, results, and remaining work. Saved evaluation records identify the implementation version and execution environment. PWDB evaluations use simulated virtual adults; their scope and comparison with published results are described at project level.
